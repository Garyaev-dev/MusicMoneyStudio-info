Назначение

MusicMoney Studio предназначена для личной работы Ivan Garyaev с музыкальными материалами, планами публикаций и собственными подключёнными аккаунтами. Эта информационная страница не предоставляет публичный доступ к рабочей Studio.

Подключение и действия

Перед использованием подключённых функций необходимо ознакомиться с политикой конфиденциальности и согласиться с применимыми условиями. Подключать можно только аккаунты, которыми пользователь вправе управлять. Согласие на подключение, разрешение чтения статистики и согласие на действие с конкретным материалом имеют разное назначение.

Пользователь отвечает за права на выбранные материалы и точность параметров перед подтверждением отправки. Отдельное подтверждение требуется для каждой поддерживаемой операции согласно интерфейсу Studio.

Условия YouTube

Studio использует YouTube API Services. При использовании этих функций пользователь соглашается соблюдать Условия использования YouTube. Применяются правила площадки и предоставленные Google разрешения.

Доступность

Работа подключений зависит от доступности API, лимитов площадки и действительности разрешений. Studio не гарантирует бессрочное подключение или непрерывный сбор при выключенном компьютере. Подготовленный материал и локальная плановая дата сами по себе не подтверждают публикацию.
