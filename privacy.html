Приложение и владелец

MusicMoney Studio — локальное настольное приложение личного музыкального проекта Ivan Garyaev. Вопросы об обработке данных и запросы на удаление можно направить владельцу: buldozar0808@gmail.com.

Данные Google и YouTube

Studio использует YouTube API Services. В зависимости от выбранных разрешений она получает идентификатор и сведения о собственном канале, идентификаторы видео, их доступные показатели и отчёты YouTube Analytics. Для загрузки или управления видео используются выбранные владельцем файлы, название, описание, обложка, параметры видимости и расписания.

OAuth-токены нужны для обращений к разрешённым API и обновления доступа. Пароль Google в Studio не вводится. Применяется также политика конфиденциальности Google.

Цели и получатели

Данные используются для показа статистики собственного канала, истории показателей и выполнения отдельно подтверждённых действий с материалами. Запросы к YouTube передают Google идентификаторы запрашиваемых объектов и, при подтверждённой отправке, выбранные материалы и параметры.

Данные Google API не продаются, не используются для рекламного таргетинга или обучения обобщённых моделей ИИ. Доступ помощника к защищённой статистике требует отдельного разрешения владельца; включение обычного подключения такого разрешения не даёт. Владелец отдельно выбирает внешние инструменты и передаваемые им материалы.

Использование и передача информации, полученной через Google API, должны соответствовать Google API Services User Data Policy, включая требования Limited Use.

Где хранятся данные

Рабочие данные находятся на компьютере владельца. На Windows токены защищены DPAPI текущего пользователя. Сохранённые защищённые отчёты хранятся зашифрованно. Файлы материалов и завершённые резервные копии могут попадать в настроенную владельцем систему синхронизации или резервного хранения.

Исторические показатели могут храниться без отсечения по возрасту при действующем согласии и необходимых проверках источника. YouTube требует периодической проверки сохранённого разрешения; сбой или отсутствие проверки не продлевают срок действительности данных. Отзыв доступа и удаление данных обрабатываются отдельно от возраста измерения.

Отзыв и удаление

Доступ можно отключить в Studio или отозвать через настройки безопасности Google. Сохранённые отчёты можно удалить средствами Studio; по вопросам удаления, включая резервные копии и сделанные владельцем экспорты, следует обратиться по указанному выше адресу.

Отзыв согласия прекращает разрешённое использование связанных данных. Удаление данных из Studio не удаляет видео или статистику на YouTube. Для удаления материалов на самой площадке используются средства YouTube либо отдельно подтверждённая поддерживаемая операция.
